# Selección de Frameworks

## Cliente

**Windows:** WPF (Windows Presentation Foundation)
- XAML for UI
- Native Windows integration
- Threading: async/await

**macOS:** SwiftUI + Cocoa
- Native performance
- SwiftUI for UI
- AVFoundation for FileWatcher

**Linux:** GTK 4 / Qt 6
- GTK4: Modern, lightweight
- Qt6: Más features pero heavier

## Servidor

**Framework:** Actix-web (Rust)
- High-performance async
- Middleware ecosystem
- TLS built-in

**ORM:** SQLx (Rust)
- Type-safe SQL queries
- PostgreSQL native

**Message Queue:** rdkafka (Rust)
- Apache Kafka client
- High-throughput async
- Distributed event streaming
