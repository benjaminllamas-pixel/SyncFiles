# Cliente macOS

## Requisitos

- macOS 10.15+ (Catalina)
- 50MB espacio en disco
- 150MB RAM

## Componentes

**UI:** SwiftUI + Cocoa
- Menu bar icon
- Finder integration
- Native notifications

**File Watcher:** FSEvents
- Latency: 100ms
- Eficiente con archivos grandes

**Almacenamiento:**
- Keychain Services (claves)
- UserDefaults (preferencias)
