## 1. Arreglar compilación del server (middleware Transform trait bounds)

### Problema
El server no compilaba tras cambios de archify. Los middlewares `from_fn` usaban firmas que no cumplían bounds de `Transform` en actix-web 4.

### Solución
En `syncfiles-server/src/middleware/mod.rs`, los middlewares `trace_context`, `rate_limit`, y `content_type_validator` usan `Next<impl MessageBody + 'static>` y devuelven `Result<ServiceResponse<BoxBody>, actix_web::Error>`.

```rust
pub async fn trace_context(
    req: ServiceRequest,
    next: Next<impl MessageBody + 'static>,
) -> Result<ServiceResponse<BoxBody>, actix_web::Error> {
    ...
}
```

## 3. Tests de seguridad del server (`syncfiles-server/tests/api_endpoints.rs`)

### 3.1 Sesión expirada
- Login → obtienes session → expirar sesión manualmente (DB `expires_at` pasado) → request con token expirado → 401.

### 3.2 Rate limiter (burst / window / aislamiento)
- Primeras N requests dentro del burst → 200.
- Request N+1 → 429.
- Ventana de tiempo: después de `window_secs`, el contador se reinicia.
- Aislamiento por IP: IP A agota burst, IP B sigue funcionando.

### 3.3 Content-Type middleware
- Requests a `/api/` con `Content-Type` incorrecto → 415.
- Requests sin Content-Type → 415 (excepto endpoints configurados).

### 3.4 Path traversal y rutas absolutas
- **Traversal:** `../../etc/passwd` → rechazado (400).
- **Ruta absoluta:** `/etc/passwd` (leading slash) → **fix aplicado:** normalización rechaza rutas absolutas. Antes se convertían silenciosamente en relativas.
  ```rust
  // src/handlers.rs — normalize_relative_path
  if path.is_absolute() || path.components().any(|c| c == ParentDir) {
      return Err(AppError::InvalidPath);
  }
  ```
